# Sample data description

The bundled datasets are synthetic hookworm-style demonstration data for testing and teaching the ARStat workflow. They are not real experimental results.

| File | Assay | Species label | Isolates | Drug | Purpose |
|---|---|---|---|---|---|
| `egg_hatch_example.csv` | Egg hatch | *Ancylostoma caninum* | WMD, KGR | Thiabendazole | Demonstrates hatch-inhibition analysis from egg and L1 counts. |
| `larval_development_example.csv` | Larval development | *Ancylostoma caninum* | WMD, KGR | Ivermectin | Demonstrates development-inhibition analysis from developed and undeveloped counts. |
| `motility_example.csv` | Motility | *Ancylostoma caninum* | WMD, KGR | Ivermectin | Demonstrates control normalization and motility-inhibition IC50 analysis from continuous activity units. |
| `survival_example.csv` | Survival/mortality | *Ancylostoma caninum* | WMD, KGR | Ivermectin | Demonstrates mortality analysis from alive/dead counts. |

WMD is used as the susceptible reference isolate in the examples. KGR is used as a resistant demonstration isolate.
